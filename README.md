# Smooth HUD (Minecraft 1.20.1, Forge 47.x)

## Что внутри
- HUD в левом верхнем углу из обрезанного пиксельного ассета:
  - сердце пульсирует (сильнее при низком здоровье);
  - красные гнёзда - здоровье, синие - выносливость (голод);
  - гнёзда плавно заполняются, при заполнении "пукают";
  - сердце бьётся двойным «тук-тук» (чаще при низком здоровье), вспыхивает при уроне;
  - по заполненным гнёздам периодически проходит блик;
  - при уроне полупрозрачная часть показывает потерянное значение.
- Тонкие шкалы брони и воздуха под HUD (появляются при необходимости).
- Панель из 4 слотов внизу экрана: всегда видна, окно плавно скользит за выбранным слотом (все 9 хотбар-слотов доступны).
- Собственный инвентарь (клавиша E) в изометрической сетке:
  - плавное появление и выезд снизу;
  - подсветка наведённого слота с пульсацией;
  - прочность предметов в процентах;
  - предмет на курсоре плавно следует за мышью;
  - Shift+клик - быстрое перемещение.

Стандартные сердца, голод, броня, воздух и хотбар скрыты.

## Сборка
1. JDK 17.
2. В папке проекта (если нет gradlew): `gradle wrapper`.
3. `./gradlew build` (Windows: `gradlew.bat build`).
4. Готовый мод: `build/libs/smoothhud-1.0.0.jar` - в папку `mods/`.
5. Тест в игре: `./gradlew runClient`.

## Настройка
- Размер и положение HUD: `HUD_MARGIN` в `SmoothHudOverlay.java`.
- Скорость анимаций: параметры `SmoothValue(speed, ghostSpeed)`.
- Высота "пука" гнёзд: `POP_AMP`, длительность `POP_TIME`.
- Геометрия инвентаря: `HW`, `HH`, `originY()` в `SmoothInventoryScreen.java`.

## Ассеты
Исходники обрезаны из пиксельного HUD и уменьшены под масштаб 0.14:
`assets/smoothhud/textures/gui/hud/` (hud_bg, heart, gem_red, gem_blue) и
`assets/smoothhud/textures/gui/inventory/` (cell, cell_glow).

## Сборка через GitHub

1. Создай репозиторий на GitHub и загрузи в него содержимое этой папки
   (архив распаковывать не нужно, файлы должны лежать в корне репозитория):
   ```
   git init
   git add .
   git commit -m "Smooth HUD mod"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/smoothhud.git
   git push -u origin main
   ```
2. Открой вкладку **Actions**. Сборка запустится сама при push.
3. Готовый jar: страница запуска сборки -> раздел **Artifacts** -> `smoothhud-jar`.
4. Чтобы выложить релиз с jar, создай и отправь тег:
   ```
   git tag v1.0.0
   git push origin v1.0.0
   ```
   jar появится во вкладке **Releases**.

Если сборка упадёт, открой лог шага **Build mod** и пришли текст ошибки.
